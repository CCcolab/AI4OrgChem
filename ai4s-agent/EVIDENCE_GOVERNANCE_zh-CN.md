# 证据治理

AI4S Agent采用以下约束防止语言模型输出取代科学证据：

- 每项命题先冻结体系、几何、电子态、方法、公式、符号和容差；
- 机器结果必须能够追溯到协议ID和来源文件；
- 原著公开数值、项目独立计算、AI预测和解释文字分层保存；
- source-proxy不冒充历史Cartesian坐标身份复现；
- 不同Target或不同状态合同的能量不得未经定义直接求和；
- 模型训练结果不能替代量子化学论证；
- 解释Agent只能读取获准证据，输出必须附带引用和适用边界。

## 统一证据状态

| 状态 | 进入条件 | 对外含义 |
|---|---|---|
| `SUPPORTED_WITHIN_SCOPE` | 同一estimand数值通过，且受测域门禁通过 | 只能带范围称“支持” |
| `PARTIAL` | 仅子命题、单体系或趋势通过，或保留关键反例 | 只能称“部分支持” |
| `OPPOSED` | 同一estimand和等价协议下方向或数值明确不符 | 可称该estimand不支持 |
| `INDETERMINATE` | 证据不足、收敛失败或关键方法缺失 | 不得强判 |
| `INCOMPARABLE` | 估计量、参考态、符号、构象规则、温度或标准态不同 | 不得投票、平均或互相覆盖 |
| `DERIVED` | 只由其他命题汇总，没有新增数据 | 不计入独立验证数量 |

P07属于`DERIVED`命题级综合；P12的精确起始尺寸属于跨估计量`INCOMPARABLE`，其总体状态仍为`PARTIAL`。这些状态不改变已冻结的数值，只约束证据身份和对外表述。
