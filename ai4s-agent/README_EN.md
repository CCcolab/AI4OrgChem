# AI4OrgChem AI4S Agent

[中文目录说明](README.md) (Chinese)

The Agent organizes scientific propositions, calculation tools, evidence governance, bounded molecular learning, symbolic exploration, and source-aware explanation into an auditable workflow.

- [Evidence governance](EVIDENCE_GOVERNANCE_EN.md)

The public package exposes architecture, frozen evidence, selected evaluation results, and reproducible core software. It does not include the complete local Web UI, model weights, caches, private run directories, or a deployable production Agent runtime. Routine evidence workflows are described as **M1+ (auditable)**. A narrowly registered external-action replay reached **M2-scoped**; it is not a published full external-model session or an external scientific benchmark, and does not raise the scientific evidence grade.
