# AI4S Agent system architecture

[Chinese original](SYSTEM_ARCHITECTURE_zh-CN.md)

1. **Scientific propositions:** define falsifiable systems, states, formulas, signs, tolerances, and stopping conditions.
2. **Calculation tools:** generate machine evidence through quantum chemistry, LFMO, conditional SCF, structural analysis, and energy ledgers.
3. **Evidence governance:** preserve protocols, sources, configurations, results, validators, and scope; prevent incompatible state contracts from being combined.
4. **Learning and discovery:** test bounded learnability with equivariant molecular models, active learning, and symbolic regression.
5. **Explanation and delivery:** retrieve approved evidence read-only and produce source-linked, scoped explanations without changing frozen conclusions.

The LLM assists with orchestration, tool use, coding, anomaly detection, and evidence organization. Scientific findings depend on physical definitions, numerical calculations, and repeatable checks, not on the LLM's assertions.
