# Evidence governance

[Chinese original](EVIDENCE_GOVERNANCE_zh-CN.md)

Each proposition freezes its system, geometry, electronic state, method, formula, sign, and tolerance before evaluation. Machine results must trace to a protocol and source file. Published monograph values, independent calculations, AI predictions, and explanatory prose remain separate. Source-proxy work is not presented as historical-coordinate identity reproduction; energies from different targets or state contracts are not summed without a defined bridge. Model training does not replace quantum-chemical evidence, and the explanation Agent reads only approved records with citations and scope.

| Status | Entry condition | Public meaning |
|---|---|---|
| `SUPPORTED_WITHIN_SCOPE` | Same-estimand numerical test and domain gates pass | Support only within the tested scope |
| `PARTIAL` | Only a subclaim, one system, or a trend passes, or a key counterexample remains | Partial support only |
| `OPPOSED` | Direction or value disagrees under the same estimand and equivalent protocol | The tested estimand is not supported |
| `INDETERMINATE` | Insufficient evidence, failed convergence, or missing key method | No firm classification |
| `INCOMPARABLE` | Estimand, reference state, sign, conformer rule, temperature, or standard state differs | Do not vote, average, or overwrite |
| `DERIVED` | Synthesis of other propositions without new data | Not another independent verification |
