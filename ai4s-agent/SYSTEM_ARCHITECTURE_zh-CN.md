# AI4S Agent 系统架构

AI4OrgChem由五个面向科学研究的能力层组成：

1. **科学命题层**：将原著挑战转化为对象、状态、公式、符号、容差和停止条件明确的可证伪任务；
2. **计算工具层**：调用量子化学、LFMO、条件SCF、结构分析和能量账本工具生成机器证据；
3. **证据治理层**：保存协议、来源、配置、结果、验证器和适用边界，阻止不同状态合同被错误混合；
4. **学习与发现层**：使用等变分子模型、主动学习和符号回归检验有界可学习性并提出候选关系；
5. **解释与交付层**：通过只读证据检索和交互界面生成带来源的范围化说明，不修改冻结科学结论。

```text
科学问题
   ↓
协议与状态冻结
   ↓
量子化学工具执行
   ↓
机器验证与证据治理
   ↓
分子学习 / 主动学习 / 符号发现
   ↓
证据增强解释与公开交付
```

LLM负责研究编排、工具调用、代码协作、异常定位和证据组织；科学真值仍由物理定义、数值计算和可重复验证决定。
