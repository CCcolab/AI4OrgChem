# AI4OrgChem AI4S Agent

AI4OrgChem 是面向基础有机化学理论验证的 AI for Science Agent。它把科学命题、量子化学工具、证据治理、分子机器学习、符号发现和范围化解释组织成可审计研究闭环。

本目录只呈现适合外部读者理解和核查的内容：

- Agent系统架构；
- 科学与AI能力；
- 量化评估摘要；
- 证据治理方式；
- 已知限制与禁止外推范围。

内部工作包编号、开发日志、调试过程、缓存和API凭据不在GitHub公开结构中出现。

GitHub首版公开的是Agent架构、冻结证据、评估摘要和部分可复核软件，不包含完整本地WebUI、模型权重、缓存、私有运行目录或完整生产运行时。因此，本目录用于公开核查Agent的证据治理和有界工程结果，不等同于可直接部署的完整Agent产品。

本项目的公开成熟度分为两个不混同的层次：常规证据工作流为 **M1+（可审计）**；V0.3的WP5在一个严格限定场景达到 **M2-scoped**，其含义仅是“外部模型选择一个注册白名单重放动作，由本地编排器在洁净、仅含发布bundle的环境中执行并复现端点”。完整外部模型会话未公开，仓库也不是可直接部署的完整Agent运行时，因此`externally_replayable_agent_runtime=false`。该M2-scoped成熟度不提升R1–R3科学证据等级，模型名称、内部9/9检查或十四项文件完整性验证也不替代Agent外部基准。
