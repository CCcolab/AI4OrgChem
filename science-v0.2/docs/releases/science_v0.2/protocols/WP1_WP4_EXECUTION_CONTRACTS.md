# Science V0.2 WP1–WP4 执行前合同

本文件冻结后续计算的选择规则，防止看到结果后更换方法、几何、估计量或“核心点”。它不构成计算授权。

## WP1：P09-B 环丁二烯普通物理态

### 唯一主高等级锚点

- 体系：中性 CBD 最低单重态；`D2h` 矩形最低点和 `D4h` 正方驻点。
- 几何：沿同一自动异构化路径，由状态平均 CASSCF 连续跟踪后冻结；主路径不得用 V0.1 条件态 GL 几何替代。
- 主观测量：`Delta_E_auto = E_S0(D4h)-E_S0(D2h)`。
- 主锚点：Quantum Package `v2.2.2`、提交 `0f320db735bfdbdf9861c9cad9f3f64175cc8c3c`（源码内部 `VERSION=2.3.1`）实现的 CIPSI+PT2；冻结 C 1s、`cc-pVDZ`，报告逐次迭代的变分能、PT2 修正、PT2 统计误差、方差、行列式数、随机种子、外推截距和外推不确定度。其他 selected-CI 实现不得并列为主锚点。
- 备用锚点：只有主程序不可获得或连续三次出现可审计资源失败时，才允许用 `CCSDT/cc-pVDZ`；备用结果不得伪装成 selected-CI 身份。
- 主锚点不按“哪个更接近原著”择优。

### 多参考阶梯

`CAS(4,4)` 仅是最低 π 活动空间。主敏感性空间为 `CAS(12,12)` 候选，须由轨道角色和 NOON 再确认；若轨道选择不连续，保持 `INDETERMINATE`。采用两根等权 SA-CASSCF 进行路径跟踪，最终基态能另报 state-specific 检查；后相关主变体固定为 SC-NEVPT2。所有 D2h/D4h 解、broken-symmetry 解、`<S^2>`、NOON、根重叠和单重–三重能隙均保留。

## WP2：三程序普通态复算

核心点以 [`configs/science_v0.2/wp2_core_anchors.json`](../../../../configs/science_v0.2/wp2_core_anchors.json) 为唯一清单。每一点必须同时有 PySCF、ORCA、Psi4；不得在运行后把困难点降为“扩展点”。

在第一项科学锚点前，先以不进入结论的水分子/乙烯小烟测确认：B3LYP 交换相关组成、球/笛卡尔基函数、网格、SCF 阈值和无 RI/DF 近似完全对齐。若某程序无法实现 Gaussian-style B3LYP，同点只能标记 `INCOMPARABLE`，不能计算差值后再放宽容差。

## WP3：P10-B 苯机制干预

### 三个坐标

1. `B2u`：Kekulé 键长交替主坐标；
2. `A1g`：全对称环呼吸对照；
3. `E2g`：简并的面内环弯曲对照，两个正交分量都要保留。

每个坐标由 D6h 冻结几何的内部坐标梯度构造，按原子质量加权，投影平移/转动后归一化。`E2g` 两分量使用确定性 Gram–Schmidt 顺序并一起哈希。执行前必须通过：归一化、互相正交、Eckart 条件、正负位移几何对称、点群投影字符和简并子空间不变性。手写交替键几何不能替代该向量。

Gate V2-0 只验收并冻结上述预注册坐标种子、对称性标签、归一化、刚体投影、正负位移和步长；不把它们称为 Hessian 正常模。Hessian 仅在 WP3 另行授权后于 Gate V2-3 计算。对简并或近简并模式比较本征子空间重叠或主角，不强制逐个本征向量的符号和方向一致；原始种子永久保留，不得根据计算结果事后替换。

### 唯一电子结构干预

- 普通支路：未屏蔽闭壳层 RKS；
- 干预支路：复用 P09 已冻结的三个 Kekulé 片段 `A=(C1,C2), B=(C3,C4), C=(C5,C6)` 及 2011-style conditional-SCF 屏蔽语义，关闭片段间 π Fock/overlap 与冻结的交换积分类别；
- 连续跟踪：每一步以 `Q=0` 的片段 π 子空间为参考，使用非正交投影和最大重叠匹配；最小奇异值低于 `0.90`、片段维数改变或根重叠低于 `0.90` 即失败，不得临时重分片；
- 对称性：普通支路保持相应位移子群；干预支路允许屏蔽定义导致的预注册对称降低，但不得允许额外自发破缺后只挑最低能根；所有根均保存。

主因果量是 `Delta_k_e = k_e(localized)-k_e(ordinary)`。正值表示普通 π 响应更偏向 B2u 畸变，负值表示普通 π 响应更偏向键长均一化。`E_N` 在同几何两支路相同，只作账本闭合，不以其绝对幅度单独证明因果。

## WP4：P12 双支路

### WP4-A / P12-A

只实现原著 CESE 账本：`CESE = Delta_EA - sum(Delta_EAm) - sum(Delta_EnAm)`。几何、条件态和符号全部 source-aligned；不得引入低能物理构象后仍称同一 estimand。

### WP4-B / P12-B 唯一主 estimand

主估计量固定为 ISE-II 反应 `A+B -> C+D` 的 0 K ZPVE 校正 ASE：

`ASE_0K = [E0(C)+E0(D)] - [E0(A)+E0(B)]`

其中 A/C 是 indene/isoindene 型融合异构体，B/D 是反–顺构型不匹配校正所需的饱和参考；四种物种均采用无约束、无虚频的最低已验证构象。正值表示芳香稳定，负值表示反芳香去稳定。主方法为 B3LYP/6-31G(d)，气相、0 K 电子能加 ZPVE。298.15 K、1 atm 的 `Delta_G`、构象 Boltzmann 集合、BLA/NICS/磁响应均为次终点，不得投票改写主 ASE。

先导集固定为 `8/10、16/18、32/34`。每个 N 必须覆盖两种独立构象来源；4n 体系同时运行闭壳层、broken-symmetry 和必要低自旋/高自旋检查。主停止标准为：连续两轮新增候选中，均未发现比当前最低点低 `0.5 kcal/mol` 以内的新极小值；否则该 N 保持 `INDETERMINATE`。

能量非芳香等价区间固定为 `[-2.0,+2.0] kcal/mol`。变化点必须报告区间，不以单个 N 作为无误差“精确起点”。WP4-A 与 WP4-B 默认 `INCOMPARABLE`，数据目录、判定和报告完全分开。
