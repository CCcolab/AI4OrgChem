# File inventory and integrity manifest

The [SHA-256 release manifest](sha256-manifest.json) is machine-readable and records hashes of the public package. The generated [file inventory](FILE_INVENTORY.md) has **Chinese-language headings and notes**; filenames, byte counts, and hashes remain directly inspectable. Both are refreshed together after authorized public-file changes. This short English landing page does not translate or duplicate the generated inventory.
