## 1. 唯一受测问题

P02不检验能量符号，也不判断电子作用与核排斥的因果分量。唯一问题是：在原著声明的氮桥多烯醛实验体系中，当UV证据表明氮孤对与2-萘基支链的共轭参与更强时，实验结构是否必然更平面且C–N键更短。

## 2. 冻结样本

### 2.1 UV样本

- Table 1-1中的10个`1-1-(m,n)`目标化合物；
- 芳香支参考系列`1-3-(m)`，`m=0,1,2`；
- 多烯醛支参考系列`1-4-(n)`，`n=0,1,2,3`。

波长以原著Table 1-1的Å为输入，换算为`y = 10^4/lambda(Å)`，同系因子为`x=(1/2)^(2/N)`。芳香支使用`N=3+m`，多烯醛支使用`N=2+n`，分别作普通最小二乘`y=a+b*x`。

### 2.2 结构样本

主检验只包含具有原著所引1984年X射线值的两个化合物：

- `1-1-(1,1)`：UV双峰表明芳香支和多烯醛支均参与；
- `1-1-(1,2)`：UV主峰归入多烯醛支，芳香支参与弱于前者。

B3LYP优化结构、`1-2-(1,n)`的N–H理论序列、平面约束结构和PES均排除在P02主检验之外；它们属于P03候选证据。

## 3. 可证伪方向判据

传统“共轭增强必然使体系更平面并缩短连接键”的局部预测为：

`theta(1,1) < theta(1,2)`且`r_CN(1,1) < r_CN(1,2)`。

若UV复核确认`1-1-(1,1)`的芳香支参与强于`1-1-(1,2)`，而两个实验结构差均为正：

`Delta theta = theta(1,1)-theta(1,2) > 0`

`Delta r_CN = r_CN(1,1)-r_CN(1,2) > 0`

则P02的有限命题“更强的该支链共轭可以与更大扭曲和更长C–N键同时出现”获得支持。该结果不能单独证明扭曲的能量驱动力；后者属于P03。

## 4. 统计与来源限制

- UV参考线报告斜率、截距、`R^2`、RMSE以及与原著印刷公式的差值；
- 结构比较是一个预先指定的成对方向检验，只有两个结构和两个相关观测量，不计算虚假的显著性`p`值；
- 原著公开PDF提供实验数值和原始文献引用；若原始CIF、标准不确定度或完整晶体学表未取得，必须标记为`published_value_reanalysis`，不得表述为原始坐标独立再精修；
- RSC 1960论文只作为`1-4-(n)`参考系列的外部文献元数据，不替代原著目标化合物数据。
