# P12轮烯CESE独立复算协议 v0.3.2

- 发布版本：`v0.3.2`
- 判定：`P12_CONSISTENT`
- 原著程序代码：不使用
- 历史程序身份复现：不声明

## 判定问题

以相同CESE估计量独立复算N12、N14和N16，检验原著关于轮烯尺寸边界的
方向性科学判断。三点构成本次公开证据范围，不是“一致”标签的条件性后缀。

## 固定体系

| 点 | 构型 | 判据 |
|---:|---|---|
| N12 | `[12]-555` | `CESE > 0` |
| N14 | `[14]-665` | `delta_EA < 0`、`ESE < 0`、`CESE < 0` |
| N16 | `[16]-5555` | `delta_EA > 0`、`ESE < 0`、`CESE < 0`且相对CESE不超过10% |

N18、N20和N22未用于本次P12判定，也不是`v0.3.2`待完成项。

## 计算合同

- 所有状态均采用全平面构象；
- 几何优化与能量均采用`B3LYPG/6-311G(2df,p)`；
- G、GL与GE状态分别计算；
- 使用`ESE = delta_EA - sum(delta_EAm)`；
- 使用`CESE = ESE - sum(delta_EnAm)`；
- N16的全部28个GE双键对直接计算，不采用旧版`8+1`对称加权；
- 不按原著印刷值拟合，不以跨估计量ASE结果作为支持票或反对票。


## N16 两种百分比的分母

| 比较量 | 数值 | 计算依据 |
| --- | ---: | --- |
| 项目 CESE | −0.339527 kcal/mol | 展示舍入值；原账本为 −0.33952721462311064 |
| 原著 CESE | −0.65 kcal/mol | 印刷值 |
| 两个展示值的绝对差 | 0.310473 kcal/mol | `abs(-0.339527 - (-0.65))` |
| 相对原著幅度差 | 约 47.7651% | `0.310473 / abs(-0.65) × 100%`，仅使用上述舍入值 |
| 注册相对 CESE | 2.103137% | `abs(CESE) / abs(sum_delta_EAm + sum_delta_EnAm) × 100%`，使用原账本未舍入标量 |

注册分母为 `abs(17.426664112539722 + (-1.282813532688139)) = 16.143850579851583 kcal/mol`。
有符号项先求和再取绝对值，**不是逐项绝对值之和**，也不是原著 CESE 的幅度。
因此“2.103137%”不表示与原著仅差 2.10%。方向判据、注册边界与幅度差应分别报告。
该说明未改变原始能量、注册门槛、P12 判定或历史运行身份，也不增加 N18/N20/N22 计算。

## 判定规则

三点各自的注册方向判据全部通过，且没有同估计量反证时，P12判定为
`P12_CONSISTENT`。数值差异、方法身份和证据点列表作为独立元数据披露，
不写成“部分一致”“有条件一致”或“暂定一致”。
