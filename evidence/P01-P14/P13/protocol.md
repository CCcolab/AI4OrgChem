# P13多环苯系烃范围化论证协议v0.1

## 1. 原著命题

多环苯系烃存在多个局域几何候选。原著提出先用GL六元组规则筛选候选，再用位置规则和能量规则选定GL几何，并通过局域能量增量组装ESE/CESE，从而统一处理不同PBH拓扑。

## 2. 唯一计算合同

- `ESE = ΔEA - ΣΔEAm`
- `CESE = ESE - ΣΔEnAm`
- `CESE/π = CESE / Nπ`
- 合格GL候选满足`N_GL = N_db + 1`
- 能量规则只允许在通过GL规则的候选集合内使用。
