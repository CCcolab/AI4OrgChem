# P07 LFMO核心命题整合协议 v0.1

- 命题：P07 扭曲需要π–π、π–σ、σ–σ及轨道响应共同分析
- 协议性质：命题级证据整合，不是跨协议能量分解
- 输入：P04/Target C、P05/Target A、P06/Target B已经冻结的范围化科学记录

## 1. 可接受的整合

P07只比较三个已经独立闭合的证据账本所表达的符号、响应模式和边界：

| 命题 | 可观测量 | 冻结协议 | P07使用方式 |
|---|---|---|---|
| P04 / Target C | `E_FUD-E_DSI3` | RHF/6-31G(d)，11个有效source-proxy点 | 检查π–π端点、直接项反例和轨道响应变号 |
| P05 / Target A | `E_G-E_FUD` | RHF/6-31G(d)，Table 5-15固定0°/17°点 | 检查π–σ直接项、响应和端点的平衡 |
| P06 / Target B | `E_PDSI-E_FUL` | RHF/STO-3G，受约束B3LYPG/6-311G(d,p) source几何0°/17°点 | 检查非键σ–σ条件态端点及扭转趋势 |

每个Target内部原有闭合关系继续有效。P07不得把三个Target的Hartree数值相加，因为它们不是同一几何、同一基组、同一状态路径上的可加分量。

## 2. 判定规则

若同时满足以下条件，P07判为范围化支持：

1. P04全部有效端点为正，但π–π直接项至少存在一个负值反例；
2. P05的0°端点在容差内不确定，17°直接项为正、轨道响应为负、净端点仍为正；
3. P06两个端点均为正，并且17°端点低于0°端点；
4. 三个输入发布均通过各自验证器且哈希保持不变；
5. 输出明确记录未执行跨协议能量求和、未重构统一物理总能量。

满足上述条件只支持以下命题：在本期冻结的source-defined账本中，端点符号不能由“共轭必然稳定化—位阻必然去稳定化”的简单二项叙事先验推出，直接作用、轨道响应和不同σ/π条件态必须分别计算。

## 3. 明确边界

- 不宣称P04、P05、P06构成同一个可加总能量分解。
- 不宣称已经得到完整扭转PES、扭矩或几何优化的统一因果模型。
- 不把P06等同为普通经典位阻能。
- 不把受测域结论外推为所有分子、角度、基组或电子结构方法的普遍定律。
- 不生成生产标签，不启动MACE/PySR训练或工业级泛化。
