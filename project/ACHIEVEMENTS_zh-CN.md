# 项目成就（成果）

### 科学论证

- 完成 P01–P14 十四项主要命题的确定性分类；
- 十二项与原著一致或范围化一致；
- P11、P12 为部分一致：分别保留取代苯诱导分量异号、轮烯精确尺寸起点跨估计量不同；
- 没有发现命题级整体不一致项；
- 受测 LFMO π–π 端点在 11/11 个技术有效点上呈去稳定化方向；
- 丁二烯 GL 定义共轭能为 `+1.575676 kcal/mol`；
- 环丁二烯 ADE 为 `+53.822467 kcal/mol`；
- 苯 ESE 为 `−37.412764 kcal/mol`；
- 应变芳香 `C12H6` 端点为 `+67.086899 kcal/mol`。

### 方法与软件

- 建成一个贯穿“命题—计算—验证—学习—解释—交付”的 AI4S Agent 原型；
- 独立实现 LFMO/条件 SCF、π/σ 分类及 DSI/FUD/GL/PLG 相关计算路径；
- 建立十四项命题的协议、数据卡、报告和自动验证器；
- 完成 MACE/NequIP 有界学习基线、真实量子化学标签回流和 PySR 探索性符号发现；
- 完成 AI-06 本地只读 WebUI、3D分子/轨道查看器和带证据引用的 LLM Agent；
- 第五期 A 线 AI-01 至 AI-06 已完成，当前进入 B 线成果发布。

### 总体科学结论

本项目在冻结受测域内整体支持原著对传统理论无条件普遍化的挑战。该结论不等于十四项每个子命题均无条件一致，也不推出“共轭必然去稳定化”这一反向普遍定律。项目的学术价值恰恰在于同时保留支持证据、局部差异、状态定义和适用边界。
