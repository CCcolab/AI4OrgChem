# 项目背景

传统有机化学常用“共轭带来稳定化和促平面化”“位阻导致去稳定化”等原则解释分子结构与能量。原著从局域片段分子轨道和从头算能量分解出发，提出一组与这些经典叙事相左的论点，包括：

- 分子轨道离域不等于电子密度离域；
- 共轭作用可能伴随分子扭曲，并可能在特定状态定义下表现为去稳定化；
- 拥挤构象不必然具有更高总能量；
- π–π、π–σ、非键 σ–σ 和轨道响应必须分开核算；
- 丁二烯、芳香能、轮烯边界和应变芳香体系需要明确的理论参考状态，不能只依赖经验热化学叙事。

原著的历史程序和部分 Cartesian 坐标并未完整公开。本项目因此不追求“原厂代码复刻”，而采用公开公式、表格、数值锚点及明确标注的 source-aligned/source-proxy 协议进行独立重构。
