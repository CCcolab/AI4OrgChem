## English

The immutable `v0.3.0` tag and release assets are preserved exactly as published. External review identified that P14's deterministic classifier accepted a five-parameter STO-3G technical pilot as if it were production scientific optimization evidence. That pilot explicitly records `scientific_classification_allowed=false`; furthermore, its G and PLG maximum gradients (`0.00351562` and `0.00881764 Eh/Å`) exceed the preregistered `0.002 Eh/Å` threshold. Optimizer `success=true`, based on relative function reduction, does not cure either defect.

The `remote_tag_created=false`, `github_release_created=false`, and related “pending” fields embedded inside the immutable package describe its pre-publication build snapshot. They are not the present remote status. The actual `v0.3.0` tag, Release assets, CI run, and post-tag clean-clone verification were completed after that snapshot; current maintenance status is recorded on `main` and in this erratum.

The immediate corrective action therefore lowered P14 to **partially consistent** and prevented the old pilot from qualifying. A new same-protocol B3LYPG/6-31G(d) production calculation then closed the missing step: G/PLG maximum gradients are `0.00146286/0.00116557 Eh/Å`, both optimizers terminated on the registered projected-gradient criterion with no active bounds, and SCF, electron-count, energy-closure, commutator, density-idempotency and memory checks all passed. The optimized `dΔr` is `0.172204 Å` versus the source `0.179 Å`; the optimized endpoint is `+67.679719 kcal/mol` versus `+67.08 kcal/mol`. Both residuals satisfy the preregistered tolerances. P14 is therefore restored to **consistent** only after this qualified evidence was added.

At completion of this P14-only correction, the proposition-level summary was **12 consistent or scope-consistent, 2 partially consistent, 0 globally inconsistent, 0 unknown**. That dated aggregate is superseded on current `main` by the P11-B update stated above. P14 remains limited to one C12H6 planar-D3h five-parameter source-proxy system; no full-Cartesian frequency, wider-symmetry, nineteen-molecule, or universal-law claim is made.

The Agent maturity wording is also scoped: WP5 demonstrated one external-model-selected, registered whitelist replay executed by a local orchestrator in a clean bundle-only environment (`M2-scoped`). It does not publish the full external model session or provide a generally externally replayable Agent runtime, and it does not alter R1–R3 scientific evidence grades.
