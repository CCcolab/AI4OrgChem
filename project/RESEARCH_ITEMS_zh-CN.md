# 项目研究项

本项目不是把 P01–P14 当作十四个彼此孤立的最终理论，而是把它们作为检验原著核心挑战所需的分层证据链。主要研究项如下：

| 研究主线 | 研究问题 | 对应证据任务 |
|---|---|---|
| **轨道离域与电子离域** | 分子轨道离域是否等同于电子密度离域；局域化表示改变是否必然改变物理电子态 | P01 |
| **共轭、结构扭曲与位阻** | 共轭是否必然稳定并促平面化；电子作用和核排斥如何共同决定扭曲及拥挤构象 | P02、P03 |
| **LFMO π–σ 能量分解** | π–π、π–σ、非键 σ–σ 和轨道响应在冻结状态合同下分别呈现什么方向；传统二项解释是否充分 | P04–P07 |
| **丁二烯共轭命题** | 选择性氢化热和中央单键缩短是否足以证明共轭稳定化；GL 定义下能量符号如何 | P08 |
| **芳香与反芳香能量** | 苯和环丁二烯的芳香能能否通过无参数局域/虚拟参考构造；苯高对称性的电子与核贡献如何分配 | P09、P10 |
| **芳香性适用边界** | 呋喃、取代苯、轮烯及大环体系能否沿用单一苯型判据；尺寸、构象和估计量如何改变结论 | P11、P12 |
| **多环与应变芳香体系** | 多环苯系能量账本和规则层级能否重构；应变芳香体系的扭曲是否包含 π 离域驱动力 | P13、P14 |
| **AI for Science 工程** | 冻结科学证据能否转化为可追踪数据、等变模型、主动学习、符号发现和只读证据 Agent | 数据资格化、等变模型、主动学习、符号发现与交互交付 |

P01–P14 是项目对原著核心论点进行细化、计算化和证据化的验证路径；最终关注的是这些证据能否共同支持原著对传统理论无条件普遍化的挑战。
