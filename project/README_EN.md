# Project overview

[中文项目介绍](README.md) (Chinese)

AI4OrgChem independently reconstructs and evaluates fourteen testable propositions motivated by Zhong-Heng Yu's *Questioning Fundamental Principles of Organic Chemistry* (2024). The monograph's program code is not used.

The project asks whether familiar accounts of conjugation, steric effects, and aromaticity remain sufficient when the molecule, electronic state, method, comparison quantity, and scope are made explicit. It combines bounded quantum-chemical reconstruction, published-value reanalysis, graph evidence, and a source-aware AI4S evidence agent. These evidence types are reported separately, not counted as fourteen equivalent QM reproductions.

Start with the [English P01–P14 evidence matrix](../manuscripts/P01-P14_evidence_matrix_EN.md), the [English evidence navigator](../evidence/P01-P14/README.md), or the [rapid verification guide](../REVIEW_GUIDE_FOR_QUANTUM_CHEMISTS.md). The [publication positioning](../manuscripts/PUBLICATION_POSITIONING_EN.md) explains the manuscript's intended scientific scope. Historical project records in this directory are in Chinese unless explicitly marked otherwise.

The project challenges the unconditional use of certain chemical heuristics; it does not assert that traditional organic chemistry is globally wrong or that conjugation is universally destabilizing.
